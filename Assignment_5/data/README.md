# Input data for Assignment 5

Place one daily stock CSV per ticker in this folder, named `<TICKER>_daily_data.csv`. Required columns: Date, Open, High, Low, Close, Volume, and Adjusted. Ticker-prefixed provider headers (for example, `AAPL.Adjusted`) are accepted. Dates should be parseable as YYYY-MM-DD. Use the selected student’s own data from a reputable financial provider. The runner reads only this folder; it does not depend on Assignment_2 paths.
